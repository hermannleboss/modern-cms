## 🔸 PROMPT SPÉCIFIQUE – LARAVEL

Implémente le backend avec **Laravel**.

### Versions requises

- **PHP** : 8.3
- **Laravel** : 12.x
- **Laravel Sanctum** : dernière version compatible

### Contraintes

- API REST
- Policies & Gates
- Eloquent ORM
- Sanctum ou JWT

### Structure du projet

**Le code doit être généré dans le dossier : `./backend/laravel/`**

### À fournir

- models
- policies
- controllers Articles
- endpoint `/me`
